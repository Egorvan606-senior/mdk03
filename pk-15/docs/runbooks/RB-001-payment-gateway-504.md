# Runbook RB-001. 504 Gateway Timeout при обращении к платёжному шлюзу

**Сервис:** OrderService 2.0.0 · **Алерт:** `OrderService5xxRate` / рост ответов 504 на `POST /api/v1/orders/{id}/pay`
**Кому:** дежурный инженер (SRE / Support) · **Время реакции:** 5 минут

## Инцидент

Сервис вернул ошибку **504 Gateway Timeout** при обращении к платёжному шлюзу:
покупатели не могут оплатить заказ, в логах — `504 Gateway Timeout при оплате заказа ...`.

## Шаг 1. Диагностика

Проверьте доступность внешнего API шлюза:

```bash
curl -I https://api.payment-gateway.com/v1/ping
```

* Ответ `HTTP/2 200` — внешний шлюз **работает**, проблема на нашей стороне → **Шаг 2**.
* Нет ответа / `5xx` — сбой у провайдера → сообщите в Service Desk и сразу **Шаг 3**.

## Шаг 2. Действие

Если внешний шлюз отвечает, но локальный пул соединений исчерпался, перезапустите пул воркеров:

```bash
systemctl restart order-service-worker
```

Через 1 минуту повторите тестовую оплату служебного заказа и проверьте долю 504 на дашборде.

## Шаг 3. Эскалация

Если **через 2 минуты** статус не изменился — **немедленно** свяжитесь с дежурным архитектором
по каналу **`#emergency-sre`**. Сообщите: время начала, результат шагов 1–2, TraceId одного
неуспешного запроса. Решение об откате (`Payments__Provider=Legacy`) принимает архитектор.
