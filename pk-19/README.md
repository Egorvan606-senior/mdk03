# ПК № 19 · Генератор суточных отчётов по транзакциям питания (вариант 10)

Иванов Е.М., группа И14-23-9. C# Console App (.NET 8), Visual Studio.

**Задание (вариант 10):** C#-программа симулирует выгрузку транзакций с публичного мок-сервера
`https://jsonplaceholder.typicode.com/posts`, суммирует финансовые показатели по категориям
и создаёт отчёт в формате CSV.

* `HttpClient` с таймаутом, 3 повторами (1 с → 2 с) и кэшем последней выгрузки (`try-catch` сетевых ошибок, таймаутов, битого JSON).
* Поля ведомости — по отчётной форме из лекции: `Date`, `Category` (бюджет / коммерция), `Amount`, `Transaction_Status` + метки АРМ и оператора.
* Результат (Docs-as-Code) в `reports\ГГГГ-ММ-ДД\`: реестр транзакций CSV, итоги по категориям CSV, сводка Markdown, контрольные суммы SHA-256; журнал `reports\logs\meal_report.log` (только дозапись).
* Конфигурация: `appsettings.json` → переменные `CAMPUS_STATION_ID`, `CAMPUS_OPERATOR_ID`, `CAMPUS_SOURCE_URL` → аргументы `--date`, `--source`, `--out`.

Запуск: профиль **«Отчёт за 24.10.2026»** → F5, или `dotnet run -- --date 2026-10-24`.
Профиль **«Сбой сети (неверный адрес API)»** показывает повторы и работу по кэшу (код завершения 2).
