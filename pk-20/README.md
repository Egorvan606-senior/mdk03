# ПК № 20 · АРМ дежурного: мониторинг API и экспорт ведомости питания (вариант 10)

Иванов Е.М., группа И14-23-9. C# Console App (.NET 8) + Serilog.

**Задача АРМ (вариант 10) — «Экспортер ведомости питания столовой»:** симулировать выгрузку транзакций
питания (`https://jsonplaceholder.typicode.com/posts`), сгруппировать данные по категориям льгот
и сформировать отчётный CSV. Основа — эталонный `Program.cs` из задания: проверка доступности API,
время отклика (Stopwatch), структурированный лог Serilog в `C:\SmartCampus\Logs\arm_monitor_log<дата>.txt`,
имитация отправки метрики.

* Serilog Dual Sinks: консоль + файл с ежедневной ротацией; в каждой строке — `StationId` и `TraceId`.
* Ведомость: `C:\SmartCampus\Reports\meal_statement_<дата_время>.csv` (4 категории льгот, дотация, к оплате, средний чек).
* Метрика (имитация OTLP): `C:\SmartCampus\Logs\arm_metrics.prom` — `arm_api_up`, `arm_api_latency_ms`.
* Коды завершения: 0 — OK, 1 — сбой API/сети, 2 — деградация (отклик > 2000 мс).

Запуск: профиль **«Мониторинг и экспорт ведомости»** → F5. Профиль **«Сбой: API недоступен»** — обработка ошибки соединения.
